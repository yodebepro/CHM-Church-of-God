# CHM Live Service #1 + Permanent Watch Live Sources

Only the requested media behavior was changed.

- `CHM Live Service — CHM Church of God · Live Broadcast` remains Listen Live playlist item #1 and the initially selected source.
- Other Listen Live items can be added, edited, uploaded, archived, deleted, exported, imported, or published normally.
- Media Admin now supports a default/first-source checkbox and ordering.
- Watch Live supports YouTube, Vimeo, Google Drive, direct MP4/WebM, MP3, permanent live/embed URLs, iframe embed code, M3U and M3U8/HLS sources.
- A permanent livestream URL can remain configured so the Watch Live page automatically uses it whenever that source goes live.
- Everything else in the website remains unchanged.
