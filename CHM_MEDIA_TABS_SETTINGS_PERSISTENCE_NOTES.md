# CHM Media Control Tabs and Persistence

Only the requested Media Control behavior was changed.

- Listen Live, Watch Live, and General Media now have separate tabs and separate settings.
- Clicking a tab shows only the fields and saved records appropriate to that destination.
- Published records remain visible on the page after publishing and refresh.
- CHM Live Service remains protected as Listen Live item #1.
- Listen Live includes artist/speaker and duration settings.
- Watch Live includes stream type, poster, autoplay, and mute settings.
- JSON export is available for the current tab or for all media sources.
- JSON import merges records into existing saved media data.
- Push Media to GitHub publishes all saved media settings.
- Add, edit, archive, delete, upload, order, and default-source controls remain available.
